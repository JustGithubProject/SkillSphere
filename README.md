# 🌟 Online Education Platform

Welcome to the **Online Education Platform** project! This platform allows users to enroll in courses, take lessons, complete assignments, and earn certificates.

## 🚀 Features

- **User Authentication**: Secure login and registration.
- **Course Management**: Create and manage courses.
- **Lesson Delivery**: Structured content delivery through lessons.
- **Assignments & Tests**: Interactive assignments and quizzes.
- **Progress Tracking**: Track user progress in real-time.
- **Certification**: Issue certificates upon course completion.

## 🛠️ Technologies

- **Backend**: FastAPI, PostgreSQL, Docker
- **Frontend**: React, Axios, Styled-components
- **Deployment**: Nginx, Kubernetes
